Monthly Report Checklist

Run these four reports at month-end, then enter the numbers under Entry / Upload once logged in. About 10 minutes once you know where each number goes.

1. Provider A/R Totals

Run for the full month just closed. Use the TOTAL row for practice-wide production/collections, and the Prev. Month / YTD rows for the comparison columns. Use each provider's own row for their individual numbers.

→ Feeds: Practice Performance and the Providers table.

2. Aging Report (Patient/Guarantor)

Run with no date filter, as of today. Use the TOTALS row at the bottom.

→ Feeds: Patient/Guarantor Aging.

3. Dental Insurance Claim Aging Report

Run the "all claims" version (no minimum-age filter). Use the PRIMARY CLAIM TOTALS and SECONDARY CLAIM TOTALS rows at the bottom.

→ Feeds: Insurance Claims Aging, Primary and Secondary.

4. New Patients & Add-On Production

Pull the new-patient count for the month, and production per category for any add-on services tracked separately (Ortho, Whitening, Implants, etc.).

→ Feeds: New Patients and Add-On Services.

Tardiness and days-off come separately, straight from the doctor — not part of this list. Provider rows can also be uploaded as a CSV instead of typed in one at a time. Goals are set once under Settings, not re-entered monthly.
